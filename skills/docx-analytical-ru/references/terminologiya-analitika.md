# Терминология аналитических документов (пример — энергетика / ЦОД)

Пример глоссария из одной отраслевой ниши (энергоснабжение центров обработки данных: дизель-генераторы, ИБП, когенерация). Замените таблицу терминами своей ниши — механика (англ→рус, homoglyphs, автоскан) переносима на любой домен.

## Английское → русское

| Нельзя в тексте | Нужно |
|---|---|
| campus / campus-энергетика | **кампус / энергетика кампуса** |
| data park | **парк ЦОД** |
| cogeneration | **когенерация** |
| trigeneration | **тригенерация** |
| Tier III / IV / Tier-контур | **уровень отказоустойчивости III / IV**, **контур отказоустойчивости ЦОД** |
| primary backup | **основной резерв** |
| backup (ЦОД) | **резервное электроснабжение** |
| DD / due diligence / refresh DD | **проверка контрагентов / актуализация проверки** |
| OEM | **завод-изготовитель** |
| Disclaimer | **Оговорка** |
| Doc1 / Doc2 | **документ 1 / документ 2** |
| greenfield | **новая площадка** (проект с нуля) |
| ride-through | **бесперебойное проведение нагрузки через ИБП** |
| shortlist | **краткий список** (партнёров) |
| static UPS | **статические ИБП** |
| Executive summary | **Резюме для партнёра** / **Резюме** |
| паттерн | **типовая схема** |
| S1–S5 (в русском docx) | **С1–С5** |

## Оставить как есть

- URL, ИНН, ОГРН, отраслевые аббревиатуры (ДГУ, ИБП, ЦОД, СМР, ПНР, ТЭЦ, ГРЭС, ISO)
- Имена компаний контрагентов (с русской обёрткой при первом упоминании)
- Отраслевые обозначения оборудования вашей ниши
- N+1 (отраслевой термин отказоустойчивости)

## Homoglyphs — запрещены

Смешение кириллицы и латиницы в одном слове (например `котлонadzora`, `трубoprovodov`).

После pandoc проверять:

```bash
rg -n '[а-яА-Я][a-zA-Z]|[a-zA-Z][а-яА-Я]' ВХОД.md
```

## Автоскан перед отправкой

```bash
python3 -m markitdown "ФАЙЛ.docx" | rg -i '[a-z]{4,}' | rg -v \
  'https|ISO|<ваш-домен>|<ваши-исключения-через-|>'
```

Замените `<ваш-домен>`/`<ваши-исключения>` реальными доменами/именами вашей ниши (собственный сайт, названия компаний-партнёров, отраслевые бренды) — список исключений строится под конкретный проект, не переносится между проектами как есть.

Для pptx — тот же пайплайн через markitdown.

## Два тона

| Элемент | Внутренний docx | Внешний docx |
|---|---|---|
| Риски, налоговые/финансовые красные флаги | да | **нет** |
| «Не привлекать», дисквалификация | да | **нет** |
| Гипотезы без подтверждения | да (с пометкой) | **нет** |
| Компетенции, сценарии, референсы | да | да |
| Приглашение к ТЭО / опросным листам | опционально | да |
